## Hypothesis

Widening the Tidy Inbox funnel by using an algorithm to detect likely-to-be-deleted emails and proactively offering bulk delete will increase engagement.

## Test Design

Evolved from Tidy Inbox (2022, bulk delete emails >30 days). Cleanup Buddy detects likely-to-be-deleted emails and offers bulk delete. Compared default vs challenger experiences on mobile.

## Outcome

Bulk actions per user grew by 9X. Sessions and timespent showed small stat sig lifts.

## Nuance

Bulk delete features are consistently the strongest value propositions across IMAP-Out Rescue, ad creatives, and other contexts. With the migration to Orbit, Tidy Inbox and Cleanup Buddy have both lost discoverability. The team needs to partner with Design to find a persistent, discoverable home for these features — particularly as marketing efforts scale to drive users to them.
