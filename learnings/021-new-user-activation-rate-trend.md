## Hypothesis

Understanding new user funnel composition and activation rates will identify optimization opportunities.

## Test Design

Data analysis of daily registrations and activation rates Jan-Apr 2026. First time differentiated tracking was in place for new user funnels.

## Outcome

Daily registrations declining: 85.6K (Jan) → 76.7K (Feb) → 74.3K (Mar) → 67.8K (Apr). But activation rate (daily activated YMail user / daily registrations) rising: 72.4% → 74.2% → 73.8% → 78.1%.

## Nuance

Prior to this work, there was no tracking to differentiate between new user funnels — some users create their first Yahoo email, others bring a @gmail account and connect via SIWG. Gmail users come in with a totally different product expectation. The hypothesis is that surfacing compelling features to Gmail SIWG users can activate and retain them at higher rates. The declining registration volume + rising activation suggests the remaining registrations are higher-intent users.
