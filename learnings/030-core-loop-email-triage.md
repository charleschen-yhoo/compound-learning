## Hypothesis

Understanding the Yahoo Mail core loop — the habitual actions users take — will reveal where to invest in engagement features.

## Test Design

Behavioral data analysis of user actions across iOS and Android, segmented by FLAOT.

## Outcome

Core actions: Open (88% iOS, 91% Android), Delete (52% iOS, 53% Android), Search (17% iOS, 12% Android), Compose (15% both). The core loop is email triage: open, delete, click. Top 4 session patterns: Open Only (~20%), Open + Delete Only (~15-20%), Open + Click + Delete Only (~10-15%), Open + Click Only (~10-15%). This pattern is consistent across all FLAOT segments and across platforms.

## Nuance

The core loop is universal — Fanatics and Tourists do the same things, just at different frequencies. Today's reward is purely intrinsic: the user's own desire to keep their inbox clean. The strategic insight is that the UG team should reinforce this existing loop (not create new ones) by adding extrinsic rewards (streaks, challenges, achievements). DAU/MAU is 48%, meaning the average user is active fewer than half the days in a month — substantial headroom for frequency improvement. This analysis was the foundation for the entire Streaks/Challenges/Motivational System strategy.
