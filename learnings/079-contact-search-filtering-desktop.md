## Hypothesis
Adding contact-based search filtering on desktop web will help users find emails more efficiently, improving search success and driving incremental DAU.

## Test Design
- **Platform**: Desktop Web
- **Metric**: DAU (directly measured)
- **Status**: GA'd

## Outcome
- **+10K incremental DAU**
- GA'd and launched

## Nuance
This is one of the few RWS Squad experiments that directly measured and achieved a DAU impact (vs. engagement metrics like replies or search success rate). The +10K DAU is modest compared to the Growth Squad's biggest wins (notifications +267K [031], IMAP-Out +55.7K [038]) but validates that search improvements can move business metrics, not just engagement proxies.

Desktop web is where search is most used (search success rate: 66% desktop vs 62% mobile), and desktop users tend to be power users who rely on search for professional workflows. Improving search for these users has outsized retention value per user even if the DAU number is smaller.
