## Hypothesis

Showing contextual, meaningful prompts at the right moments will increase notification opt-in rates for users who haven't enabled Yahoo Mail web notifications.

## Test Design

Four upsell triggers tested: Compose Upsell, Message Read Upsell, Exit Intent Upsell, and Inbox Refresh Upsell (still running). Each shows a contextual prompt to opt into notifications and enable browser permissions.

## Outcome

Exit Intent Upsell: +0.58pp opt-ins (best performer). Compose Upsell: +0.53pp. Message Read Upsell: +0.22pp. Inbox Refresh: TBD.

## Nuance

Exit intent is the highest-converting moment — users leaving the session are most receptive to a "stay connected" message. 81% of users don't receive web notifications today, and only 1.25% of web sessions come from notifications, so the addressable opportunity is massive. Notifications directly correlate to increased PVs on web and can bring back logged-out users through login reminders.
