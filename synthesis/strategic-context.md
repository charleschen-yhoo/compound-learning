# Strategic Context (DAU Model, Program Aggregates)

## Summary

These learnings aren't experiment results — they're the foundational data that frames the entire growth strategy. The DAU composition model [068] establishes that 95% of DAU is continuing users, making retention the primary growth lever. The IMAP-Out aggregate [070] quantifies the program at scale: 8.6M downloads, 1.3M incremental DAU in 2025. Together, they explain *why* the team's portfolio is shaped the way it is.

## Key Data Points

**DAU Composition (as of Mar 2024):**
- New Accounts: 0.1% (57K), retention 18-44%
- Reactivated (7-30 day lapse): 3% (1.9M), retention 27-31%
- Resurrected (30+ day lapse): 1% (725K), retention 17-24%
- Continuing (active past 7 days): 95% (55M), retention 70-80%

**User Base (168M MAU):**
- IMAP-only: 40M (unmonetizable, no accurate tracking)
- IMAP + O&O: 23M
- O&O: 120M (Desktop Web 54M, Mobile App 82M, Mobile Web 16M)

**IMAP-Out Rescue Program (2025):**
- 8.6M app downloads
- 1.3M incremental DAU
- Pacing to 10M+ downloads in 2026
- 1M+ login page impressions/day from third-party clients

## Strategic Implications
- Growth = retention + frequency, not acquisition. The 95% continuing user base means a 1% retention improvement dwarfs any new user initiative.
- The 40M IMAP-only users are the largest untapped segment. IMAP-Out Rescue is the primary channel to convert them.
- Mobile retention (44% for new users) is 2.4x desktop (18%), reinforcing the desktop → mobile migration thesis.
